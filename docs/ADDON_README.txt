Neon Dial - Spotify add-on (optional)
Adds the "Standalone Spotify" mode: no Spotify app has to be open. Needs Spotify Premium.
It contains librespot (https://github.com/librespot-org/librespot, MIT licence), an unofficial open-source Spotify Connect receiver.
Install it with Vortex AFTER the main Neon Dial file. Then, in the Neon Dial window of the CET overlay, choose
Mode > Standalone Spotify, and pick the device "Neon Dial FM" in any Spotify app on the same network.
This add-on connects to Spotify's servers (that is how it plays your music). The main Neon Dial file never connects to the internet by itself.
Using an unofficial client may conflict with Spotify's terms of use; installing it is your choice.
